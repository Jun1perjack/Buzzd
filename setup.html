Server Setup

Run this once on your Steam Deck. Takes about 5 minutes.

1

Get an ngrok account

ngrok creates a public URL so your phone can reach the Steam Deck. Sign up free at ngrok.com, then copy your auth token from the dashboard.

2

Install dependencies on the Steam Deck

Switch to Desktop Mode. Open a terminal and run:

pip3 install evdev

Then install Node.js if you don't have it (via the Discover store or nodejs.org).

If pip3 install evdev fails, try running inside a Distrobox container or enable Developer Mode in Steam Settings first.
3

Set uinput permissions (once)

The virtual controller needs access to /dev/uinput:

echo 'KERNEL=="uinput", GROUP="input", MODE="0660"' | sudo tee /etc/udev/rules.d/99-uinput.rules
sudo udevadm control --reload-rules && sudo udevadm trigger
sudo usermod -aG input $USER

Then log out and back in (or reboot) for the group change to apply.

4

Download and configure the server

git clone https://github.com/Jun1perjack/Buzzd.git
cd Buzzd/server
npm install
cp .env.example .env

Open .env and fill in your values:

NGROK_AUTHTOKEN=your_token_here
VERCEL_URL=https://your-app.vercel.app
5

Start the server

npm start

A QR code will appear in the terminal. Players scan it to join — no room code or URL needed.

Start the server before opening PCSX2 so the virtual controller is detected.
🎮

Configure PCSX2

The server creates a virtual gamepad called Buzz Controller with 20 buttons.

In PCSX2: Settings → Controllers → USB → set port 1 to Buzz Controller → Configure → map each button.

Button order per player: BUZZ, Blue, Orange, Green, Yellow (players 1–4 use buttons 1–20 in sequence).
